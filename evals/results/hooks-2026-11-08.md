# Bootstrap skill — alpha 0.1.2

Richiesta: caricare le skill del plugin su SessionStart, SubagentStart e UserPromptSubmit.
Implementazione: testi delle due skill a start/subagent start; routing breve a ogni prompt.
Nessun hook Stop/SessionEnd attivo, acquisizione o applicazione automatica.

## Verifiche locali

- 66 test unitari passati (6 nuovi test con più eventi/input sintetici).
- Valutazione meccanica sintetica 10/10; non misura correttezza semantica.
- Ruff lint/format e controllo package passati.
- Runtime e cache plugin aggiornati a 0.1.2; doctor passa.
- Comandi effettivi dei tre eventi eseguiti dalla cache installata con PATH di sistema,
  cwd esterna e input sintetico in modalità plan: JSON valido, nessuno stderr.
- Contesto start/subagent: 6342 caratteri; richiamo prompt: 724 caratteri.
  Sono lunghezze del testo, non conteggi esatti di token.
- Contenuto privato del prompt non ripetuto nell'output. Input invalido/eccessivo e skill
  mancanti non bloccano il turno. Percorsi con spazi gestiti dal comando quotato.
- Copia installata identica ai file sorgente verificati. Nessuna modifica al file hook globale,
  agli hook Orca/Superset o alle note personali eseguita da questa implementazione.

## Limiti e attivazione

Il test dei comandi non dimostra discovery, trust e consegna automatica del contesto da parte
  del client aperto. Dopo riavvio/nuova sessione serve la revisione di attendibilità richiesta
  da Codex. Non è stato alterato il database di trust né usato un bypass.
Non è stato avviato un subagente reale: è stato verificato il contratto del suo evento tramite
input sintetico. Nessun dato personale o transcript reale è incluso in questa verifica.
Le istruzioni favoriscono il routing; non garantiscono obbedienza del modello o qualità delle
future sintesi. Il pilot semantico umano e i gate di pubblicazione restano necessari.
Ponytail non è stato reperito tra le installazioni locali ispezionate; non dichiariamo equivalenza
con una sua versione specifica.
